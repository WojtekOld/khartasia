# xntt_views Module

The xntt_views module integrates the ExternalEntity type with Drupal Views,
allowing users to display and manipulate ExternalEntity data in a flexible way.

## Usage

Once the module is enabled, you can create a new View that includes
ExternalEntity data:

1. Navigate to **Structure** > **Views** > **Add new view**.
2. In the **Show** dropdown, select **your External Entity type name**.
3. Configure the View as needed, adding fields, filters, and sorting options
  specific to ExternalEntity.
